# korean-special-education-learning-map-mcp

한국 2022 개정 특수교육 교육과정 성취기준 MCP 서버.
**기본 교육과정** 16과목과 고등학교 **특수교육 전문 교과**(직업·생활 14과목, 이료 10과목)의 성취기준 **1,490개**, 그 **내용 체계 표·성취기준 해설·적용 시 고려 사항**, 과목별 **성격·목표와 교수·학습 및 평가**, 총론의 **기본 교육과정 편성·운영 기준**(편제·시간·학점 배당표·운영 기준)을 공식 고시 원문 그대로 패키지에 내장하고, 과목·학년군·영역 축으로 탐색합니다. stdio로 완전 로컬 동작, 도구 9종.

## 설치

```json
{ "mcpServers": { "korean-special-education-learning-map": {
  "command": "npx", "args": ["-y", "korean-special-education-learning-map-mcp"] } } }
```

## 수록 범위 (v0.2)

| category | 원본 | 교육과정 | 과목 | 성취기준 |
|---|---|---|---:|---:|
| `basic` | 【별책 3】 | 기본 교육과정 | 16 | 691 |
| `special-vocational` | 【별책 2】 | 선택 중심 교육과정 특수교육 전문 교과 — 직업·생활 | 14 | 363 |

- **같은 이름의 공통 교육과정 과목:** 시각장애인 자립생활·농인의 생활과 문화는 【별책 2】의 특수교육 공통 교육과정(초·중학교)에도 같은 이름·접두어로 있습니다. 이 패키지는 고등학교 전문 교과 코드(12)만 싣습니다.
- **판본:** 전문 교과는 제2024-4호 판과 제2026-2호 판이 성취기준·내용 체계·해설·성격·목표·교수·학습 및 평가 모두 같습니다(파이프라인이 두 판을 양방향으로 대조).
- **기초작업기술Ⅰ·Ⅱ 코드:** 원문대로 로마 숫자를 씁니다(`[12작업Ⅰ01-01]`). `12작업I01-01`처럼 ASCII로 적어도 찾습니다.

### 성취기준과 함께 싣는 원문

| 원문 | 기본 교육과정 | 직업·생활 | 이료 | 도구 |

【별책 1】 총론에서는 'Ⅲ-3. 기본 교육과정 편성·운영'(49~55쪽)만 수록합니다. 총론의 나머지(인간상·핵심역량, 공통·선택 중심 교육과정 편성·운영, 교수·학습, 평가, 지원 등)는 수록하지 않습니다.

| 학교급 | 편제 | 배당 기준 | 편성·운영 기준 |
|---|---|---|---|
| 초등학교 | 4항 | <표 9> 시간 배당(1~2·3~4·5~6학년) + 주석 4개 | 12항 |
| 중학교 | 5항 | <표 10> 시간 배당(1~3학년) + 주석 3개 | 10항(세부 7항 포함 17항) |
| 고등학교 | 5항 | <표 11> 학점 배당(1~3학년) + 주석 5개 | 16항 |

<표 9>의 1~2학년 칸(건강한 생활 신설)과 초등 편제 나)는 제2026-2호 개정분입니다. 초1~2 시행일은 2028년 3월 1일입니다.

- **2026-2호 개정과 시행 시기:** 이 개정으로 초1~2 통합교과가 바뀌었습니다. '건강한 생활'이 새로 생겼고, '즐거운 생활'은 9개에서 6개로 개편됐습니다. 초1~2 시행일은 **2028년 3월 1일**이며, 그 전까지 학교 현장은 이전 고시(제2024-4호) 판 즐거운 생활 성취기준 9개를 따릅니다.
- **시행 중인 이전 판도 함께 수록:** 이전 판 즐거운 생활 9개를 `edition: "2024-4"` 표시와 함께 넣었습니다(위 표의 수에는 포함하지 않음).
  - `get_standard`는 같은 코드에 대해 두 판을 모두 돌려줍니다.
  - `search_standards`는 판 표시를 붙여 보여 줍니다.
  - `get_learning_roadmap`과 `list_subjects`는 이전 판을 `previousEdition`으로 따로 보여 줍니다.
  - 파이프라인이 양방향으로 확인합니다. 건강한 생활은 제2026-2호로 새로 생겨 이전 판에 없고, 나머지 14과목은 두 판의 성취기준이 같습니다.
- **해설·내용 체계·성격·교수·학습의 이전 판:** 바른 생활·슬기로운 생활은 성취기준은 두 판이 같지만, 제2026-2호에서 해설·고려 사항·내용 체계 안내·성격·목표·교수·학습 및 평가 문구가 다듬어졌습니다(예: '실천하도록' → '실천할 수 있도록', 건강한 생활과의 연계 문구). 그래서 즐거운 생활과 함께 이 두 과목도 2024-4호 판을 함께 싣습니다.
  - `get_standard`는 이전 판 해설을 `previousEditionNotes`로, `get_content_system`·`get_subject_guide`는 이전 판을 `previousEdition`으로 줍니다.
  - 나머지 기본 교육과정 13과목은 두 판이 같은지 파이프라인이 확인합니다.
- **수록하지 않는 것:** 교과(군)별 '교육과정 설계의 개요', 창의적 체험활동과 일상생활 활동(국가 수준 성취기준이 없음 — 일상생활 활동은 학교가 영역·내용을 정함), 【별책 2】의 유치원 교육과정·특수교육 공통 교육과정(국어(청각장애), 체육(시각장애·지체장애), 미술(시각장애), 초·중학교 시각장애인 자립생활·농인의 생활과 문화, 점자, 수어)과 공통국어(청각장애), 일반 초·중등학교 공통·선택 중심 교육과정.
- **다른 MCP 서버:** 보통교과는 [korean-secondary-learning-map-mcp](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp), 특성화고 전문교과는 [korean-vocational-learning-map-mcp](https://github.com/raphysicst-create/korean-vocational-learning-map-mcp)에 있습니다.

## 도구 9종

| 도구 | 용도 |
|---|---|
| `list_subjects` | 수록 과목과 과목별 학년군·성취기준 수, 교육과정 구분 요약 (`category` 필터) |
| `get_grade_band_overview` | 학년군별 과목·영역 개요와 그 학년군의 기본 교육과정 시간·학점 배당 (개별화교육계획 범위 잡기). 고1~3은 전문 교과 과목도 함께 |
| `get_operation_guidelines` | 학교급별 기본 교육과정 편제·배당표(주석 포함)·편성·운영 기준 원문 |
| `search_standards` | 코드·원문 키워드 + 과목·학년군·영역·교육과정 구분 필터 검색 |
| `get_standard` | 코드로 공식 원문·과목·학년군·영역과 성취기준 해설·적용 시 고려 사항·영역 안내 조회 |
| `get_content_system` | 과목의 내용 체계 표: 영역별 핵심 아이디어와 범주·학년군별 내용 요소 |
| `get_learning_roadmap` | 과목의 학년군 → 영역 → 성취기준 계층 |
| `get_subject_guide` | 과목의 성격·목표와 교수·학습 및 평가(방향·방법) 원문 계층. `part`로 한 부분만 |
| `search_subject_guides` | 모든 과목의 성격·목표, 교수·학습 및 평가 문단·항목·하위 문단 키워드 검색 |

- **교육과정 구분(`category`):** `basic`·`기본 교육과정`, `special-vocational`·`직업·생활`, `ilyo`·`이료`, `전문 교과`(직업·생활 + 이료)를 받습니다.
- **해설 구성(`get_standard`의 `notes`):** `explanation`은 그 성취기준의 해설, `considerations`는 그 성취기준을 가리키는 적용 시 고려 사항, `sharedConsiderations`는 같은 목록 상자 전체에 해당하는 고려 사항입니다. 여러 성취기준을 함께 다룬 문단에는 `sharedWith`가 붙습니다. 건강한 생활·즐거운 생활(2026-2호)은 소제목(`label`, 예: '평가 시 고려 사항')이 있습니다. 직업·생활은 원문이 해설을 달지 않은 성취기준이 있어 `explanation`이 빈 배열일 수 있습니다. `includeNotes: false`로 빼고 조회할 수 있습니다.
- **내용 체계 보기(`get_content_system`):** `gradeBand`를 주면 그 학년군 칸만 줍니다. 여러 학년군을 합친 칸은 `sharedWithGradeBands`로 알립니다. 사회·수학·과학·체육·생활영어는 범주 아래 하위 영역(`subArea`)이 있습니다. 이료 과목은 표의 '내용 요소' 아래 열이 하위 영역(예: 해부·생리 '해부학의 이해')이라 범주 × 하위 영역 행으로 펴고, 열 순서를 `subAreas`로 줍니다.
- **성격·목표, 교수·학습 및 평가(`get_subject_guide`):** `nature.sections`(성격 머리글·문단), `goals`(총괄 목표 `overall`, 세부 목표 `items`), `teachingLearning`·`assessment`(각각 `parts`: 방향 `direction`·방법 `methods`, 항목 `(가)`… 과 번호 없는 하위 문단 `subItems`)입니다. 통합교과는 성격이 '통합교과의 성격'과 '○○ 생활과의 성격' 둘입니다. 2026 건강한 생활·즐거운 생활은 항목이 소제목이고 내용이 하위 문단입니다.

- **학년군 표기:** `초3~4`, `중학교`, `고1~3`, `e3-4` 등 여러 표기를 받습니다.
- **'09' 코드:** 중학교 일부 코드는 고시 원문대로 `[09수학04-01]`, `[09생영01-01]`처럼 '09'로 적혀 있습니다. `9수학04-01`로 찾아도 됩니다.
- **통합교과 영역명:** 통합교과 4과목은 4개 영역을 중첩한 성취기준이라서 영역명을 `통합교과 4개 영역 중첩`으로 표시합니다.

## 데이터 특성 고지

- **추출과 검증:** 성취기준 코드·원문·영역명·과목 배정은 고시 PDF 조판에서 기계로 추출했습니다. 기본 교육과정 원문 691개는 서로 다른 추출기 두 가지의 출력과 글자 단위로 전량 대조했고, 과목마다 3개씩 PDF 지면과 직접 대조했습니다. 전문 교과 799개는 PDF `-raw` 출력(두 판 모두)과 코드·원문을 글자 단위로 전량 대조했고, HWP 목록 상자 원문과도 대조했습니다. 인용할 때는 고시 PDF와 대조하세요.
- **편성·운영 기준:** 총론 PDF는 단어 중간에서 줄을 바꿔 줄 이음을 되살릴 수 없습니다. 그래서 조항 원문은 같은 고시의 HWP 판에서 문단 단위로 가져와 PDF와 글자 단위로 대조했습니다. 배당표는 사람이 옮긴 뒤 HWP 표 칸과 낱낱이 대조하고, 합계를 검산하고, 지면 이미지와 대조했습니다.
