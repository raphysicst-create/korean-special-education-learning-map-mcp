# korean-special-education-learning-map-mcp

한국 2022 개정 특수교육 교육과정 성취기준 MCP 서버.
기본 교육과정 교과 성취기준 **691개**를 공식 고시 원문 그대로 패키지에 내장하고, 과목·학년군·영역 축으로 탐색합니다. stdio로 완전 로컬 동작, 도구 5종.

## 설치

```json
{ "mcpServers": { "korean-special-education-learning-map": {
  "command": "npx", "args": ["-y", "korean-special-education-learning-map-mcp"] } } }
```

## 수록 범위 (v0.1)

【별책 3】 기본 교육과정의 교과 성취기준 전량. 근거 고시는 교육부 고시 제2022-34호(2022.12.22.)이고, 국가교육위원회 고시 제2026-2호(2026.1.21.) 일부개정을 반영한 판입니다.

| 과목 | 학년군 | 성취기준 |
|---|---|---:|
| 바른 생활 | 초1~2 | 10 |
| 슬기로운 생활 | 초1~2 | 11 |
| 건강한 생활 | 초1~2 | 6 |
| 즐거운 생활 | 초1~2 | 6 |
| 국어 | 초1~2 ~ 고1~3 | 62 |
| 사회 | 초3~4 ~ 고1~3 | 49 |
| 수학 | 초1~2 ~ 고1~3 | 148 |
| 과학 | 초3~4 ~ 고1~3 | 78 |
| 실과 | 초5~6 | 23 |
| 진로와 직업 | 중1~3, 고1~3 | 57 |
| 체육 | 초3~4 ~ 고1~3 | 56 |
| 음악 | 초3~4 ~ 고1~3 | 52 |
| 미술 | 초3~4 ~ 고1~3 | 46 |
| 정보통신활용 | 중1~3, 고1~3 | 24 |
| 생활영어 | 중1~3, 고1~3 | 31 |
| 보건 | 중1~3, 고1~3 | 32 |

학년군별로는 초1~2 67개, 초3~4 103개, 초5~6 137개, 중1~3 188개, 고1~3 196개입니다.

- **2026-2호 개정과 시행 시기:** 이 개정으로 초1~2 통합교과가 바뀌었습니다. '건강한 생활'이 새로 생겼고, '즐거운 생활'은 9개에서 6개로 개편됐습니다. 초1~2 시행일은 **2028년 3월 1일**이며, 그 전까지 학교 현장은 이전 고시(제2024-4호) 판 즐거운 생활 성취기준을 따릅니다. 이 내용은 `list_subjects`의 `note`로도 안내됩니다. 다른 교과의 성취기준은 2022 원본·2024-4호 판과 같습니다.
- **수록하지 않는 것:** 창의적 체험활동과 일상생활 활동은 국가 수준 성취기준이 없습니다. 일상생활 활동은 학교가 영역·내용을 정합니다.
- **이후 버전:** 특수교육 전문 교과(직업·생활, 이료)와 공통·선택 중심 교육과정은 이후 버전에서 다룹니다.
- **다른 MCP 서버:** 보통교과는 [korean-secondary-learning-map-mcp](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp), 특성화고 전문교과는 [korean-vocational-learning-map-mcp](https://github.com/raphysicst-create/korean-vocational-learning-map-mcp)에 있습니다.

## 도구 5종

| 도구 | 용도 |
|---|---|
| `list_subjects` | 수록 과목과 과목별 학년군·성취기준 수 |
| `get_grade_band_overview` | 학년군별 과목·영역 개요 (개별화교육계획 범위 잡기) |
| `search_standards` | 코드·원문 키워드 + 과목·학년군·영역 필터 검색 |
| `get_standard` | 코드로 공식 원문·과목·학년군·영역 조회 |
| `get_learning_roadmap` | 과목의 학년군 → 영역 → 성취기준 계층 |

- **학년군 표기:** `초3~4`, `중학교`, `고1~3`, `e3-4` 등 여러 표기를 받습니다.
- **'09' 코드:** 중학교 일부 코드는 고시 원문대로 `[09수학04-01]`, `[09생영01-01]`처럼 '09'로 적혀 있습니다. `9수학04-01`로 찾아도 됩니다.
- **통합교과 영역명:** 통합교과 4과목은 4개 영역을 중첩한 성취기준이라서 영역명을 `통합교과 4개 영역 중첩`으로 표시합니다.

## 데이터 특성 고지

- **추출과 검증:** 성취기준 코드·원문·영역명·과목 배정은 고시 PDF 조판에서 기계로 추출했습니다. 원문 691개는 서로 다른 추출기 두 가지의 출력과 글자 단위로 전량 대조했고, 과목마다 3개씩 PDF 지면과 직접 대조했습니다. 인용할 때는 고시 PDF와 대조하세요.
- **가운뎃점 통일:** PDF 글꼴에 따라 섞여 나오는 가운뎃점 이형(ㆍ, ･, ⋅ 등)은 `·`(U+00B7)로 통일했습니다.
- **공식 산출물이 아님:** 교육부·국가교육위원회·국립특수교육원의 공식 산출물이 아닙니다. 개별 학생을 진단하거나 개별화교육계획을 대신하지 않습니다.
