# korean-special-education-learning-map-mcp

한국 2022 개정 특수교육 교육과정 성취기준 MCP 서버.
기본 교육과정 교과 성취기준 **691개**와 그 **내용 체계 표·성취기준 해설·적용 시 고려 사항**, 총론의 **기본 교육과정 편성·운영 기준**(편제·시간·학점 배당표·운영 기준)을 공식 고시 원문 그대로 패키지에 내장하고, 과목·학년군·영역 축으로 탐색합니다. stdio로 완전 로컬 동작, 도구 7종.

## 설치

```json
{ "mcpServers": { "korean-special-education-learning-map": {
  "command": "npx", "args": ["-y", "korean-special-education-learning-map-mcp"] } } }
```

## 수록 범위 (v0.1)

【별책 3】 기본 교육과정의 교과 성취기준 전량. 근거 고시는 교육부 고시 제2022-34호(2022.12.22.)이고, 국가교육위원회 고시 제2026-2호(2026.1.21.) 일부개정을 반영한 판입니다.

성취기준과 함께 같은 별책 3의 다음 원문도 수록합니다.

|---|---|---|

| '나. 성취기준'의 성취기준 해설 | 679문단 (현행 성취기준 691개 모두) | `get_standard` |
| 성취기준 적용 시 고려 사항 | 667문단 | `get_standard` |
| 영역·하위 영역 성취기준 안내 | 140개 절, 212개 묶음 | `get_standard` |

과목의 성격·목표, '교수·학습 및 평가', 창의적 체험활동·일상생활 활동은 수록하지 않습니다.

【별책 1】 총론에서는 'Ⅲ-3. 기본 교육과정 편성·운영'(49~55쪽)만 수록합니다. 총론의 나머지(인간상·핵심역량, 공통·선택 중심 교육과정 편성·운영, 교수·학습, 평가, 지원 등)는 수록하지 않습니다.

| 학교급 | 편제 | 배당 기준 | 편성·운영 기준 |
|---|---|---|---|
| 초등학교 | 4항 | <표 9> 시간 배당(1~2·3~4·5~6학년) + 주석 4개 | 12항 |
| 중학교 | 5항 | <표 10> 시간 배당(1~3학년) + 주석 3개 | 10항(세부 7항 포함 17항) |
| 고등학교 | 5항 | <표 11> 학점 배당(1~3학년) + 주석 5개 | 16항 |

<표 9>의 1~2학년 칸(건강한 생활 신설)과 초등 편제 나)는 제2026-2호 개정분입니다. 초1~2 시행일은 2028년 3월 1일입니다.

- **2026-2호 개정과 시행 시기:** 이 개정으로 초1~2 통합교과가 바뀌었습니다. '건강한 생활'이 새로 생겼고, '즐거운 생활'은 9개에서 6개로 개편됐습니다. 초1~2 시행일은 **2028년 3월 1일**이며, 그 전까지 학교 현장은 이전 고시(제2024-4호) 판 즐거운 생활 성취기준 9개를 따릅니다.
- **시행 중인 이전 판도 함께 수록:** 이전 판 즐거운 생활 9개를 `edition: "2024-4"` 표시와 함께 넣었습니다(위 표의 수에는 포함하지 않음).
  - `get_standard`는 같은 코드에 대해 두 판을 모두 돌려줍니다.
  - `search_standards`는 판 표시를 붙여 보여 줍니다.
  - `get_learning_roadmap`과 `list_subjects`는 이전 판을 `previousEdition`으로 따로 보여 줍니다.
  - 파이프라인이 양방향으로 확인합니다. 건강한 생활은 제2026-2호로 새로 생겨 이전 판에 없고, 나머지 14과목은 두 판의 성취기준이 같습니다.
- **해설·내용 체계의 이전 판:** 바른 생활·슬기로운 생활은 성취기준은 두 판이 같지만, 제2026-2호에서 해설·고려 사항·내용 체계 안내 문구가 다듬어졌습니다(예: '실천하도록' → '실천할 수 있도록', 건강한 생활과의 연계 문구). 그래서 즐거운 생활과 함께 이 두 과목도 2024-4호 판 해설·내용 체계를 함께 싣습니다.
  - `get_standard`는 이전 판 해설을 `previousEditionNotes`로, `get_content_system`은 이전 판 표를 `previousEdition`으로 줍니다.
  - 나머지 13과목은 두 판의 내용 체계·해설이 같은지 파이프라인이 확인합니다.
- **수록하지 않는 것:** 창의적 체험활동과 일상생활 활동은 국가 수준 성취기준이 없습니다. 일상생활 활동은 학교가 영역·내용을 정합니다.
- **이후 버전:** 특수교육 전문 교과(직업·생활, 이료)와 공통·선택 중심 교육과정은 이후 버전에서 다룹니다.
- **다른 MCP 서버:** 보통교과는 [korean-secondary-learning-map-mcp](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp), 특성화고 전문교과는 [korean-vocational-learning-map-mcp](https://github.com/raphysicst-create/korean-vocational-learning-map-mcp)에 있습니다.

## 도구 7종

| 도구 | 용도 |
|---|---|
| `list_subjects` | 수록 과목과 과목별 학년군·성취기준 수 |
| `get_grade_band_overview` | 학년군별 과목·영역 개요와 그 학년군의 시간·학점 배당 (개별화교육계획 범위 잡기) |
| `get_operation_guidelines` | 학교급별 기본 교육과정 편제·배당표(주석 포함)·편성·운영 기준 원문 |
| `search_standards` | 코드·원문 키워드 + 과목·학년군·영역 필터 검색 |
| `get_standard` | 코드로 공식 원문·과목·학년군·영역과 성취기준 해설·적용 시 고려 사항·영역 안내 조회 |
| `get_content_system` | 과목의 내용 체계 표: 영역별 핵심 아이디어와 범주·학년군별 내용 요소 |
| `get_learning_roadmap` | 과목의 학년군 → 영역 → 성취기준 계층 |

- **해설 구성(`get_standard`의 `notes`):** `explanation`은 그 성취기준의 해설, `considerations`는 그 성취기준을 가리키는 적용 시 고려 사항, `sharedConsiderations`는 같은 목록 상자 전체에 해당하는 고려 사항입니다. 여러 성취기준을 함께 다룬 문단에는 `sharedWith`가 붙습니다. 건강한 생활·즐거운 생활(2026-2호)은 소제목(`label`, 예: '평가 시 고려 사항')이 있습니다. `includeNotes: false`로 빼고 조회할 수 있습니다.
- **내용 체계 보기(`get_content_system`):** `gradeBand`를 주면 그 학년군 칸만 줍니다. 여러 학년군을 합친 칸은 `sharedWithGradeBands`로 알립니다. 사회·수학·과학·체육·생활영어는 범주 아래 하위 영역(`subArea`)이 있습니다.

- **학년군 표기:** `초3~4`, `중학교`, `고1~3`, `e3-4` 등 여러 표기를 받습니다.
- **'09' 코드:** 중학교 일부 코드는 고시 원문대로 `[09수학04-01]`, `[09생영01-01]`처럼 '09'로 적혀 있습니다. `9수학04-01`로 찾아도 됩니다.
- **통합교과 영역명:** 통합교과 4과목은 4개 영역을 중첩한 성취기준이라서 영역명을 `통합교과 4개 영역 중첩`으로 표시합니다.

## 데이터 특성 고지

- **추출과 검증:** 성취기준 코드·원문·영역명·과목 배정은 고시 PDF 조판에서 기계로 추출했습니다. 원문 691개는 서로 다른 추출기 두 가지의 출력과 글자 단위로 전량 대조했고, 과목마다 3개씩 PDF 지면과 직접 대조했습니다. 인용할 때는 고시 PDF와 대조하세요.
- **편성·운영 기준:** 총론 PDF는 단어 중간에서 줄을 바꿔 줄 이음을 되살릴 수 없습니다. 그래서 조항 원문은 같은 고시의 HWP 판에서 문단 단위로 가져와 PDF와 글자 단위로 대조했습니다. 배당표는 사람이 옮긴 뒤 HWP 표 칸과 낱낱이 대조하고, 합계를 검산하고, 지면 이미지와 대조했습니다.
- **내용 체계·해설:** 별책 3 PDF는 표 칸을 섞고 단어 중간에서 줄을 바꿉니다. 그래서 같은 고시의 HWP 판에서 표 칸(행·열·병합 범위)과 문단을 가져왔습니다.
  - 모든 문단·내용 요소를 PDF 텍스트(두 가지 추출 방식)와 공백 무시 글자 대조해 전부 찾았습니다.
  - 해설 묶음의 성취기준 목록 상자는 출시 성취기준 원문과 대조했고, 성취기준 691개가 정확히 한 번씩 나옵니다.
  - 표 구조(어느 항목이 어느 학년군 칸인지)는 수학 '수와 연산', 체육 '스포츠' 표를 지면 이미지와 칸 단위로 대조했습니다.
  - HWP 전용 기호 3종은 지면 이미지로 확인해 바꿨습니다: 세로선 `|`, 가운뎃점 `·`(포장·조립), 하위 영역 번호(①~④).
- **원문 오기 보정:** 수학 [6수학01-11]·[6수학01-12] 해설 첫머리가 원문(두 판 HWP·PDF 모두)에 `[수학01-12]`로 적혀 있습니다. 문장은 원문 그대로 두고, 이 해설이 [6수학01-12]도 가리키도록 연결했습니다. 사회 내용 체계 표의 세로쓰기 하위 범주는 띄어쓰기 정보가 없어 사회과 본문 표기('도덕적 인성', '인간과 자연의 공존', '역사·문화 소양')를 따랐습니다. 근거는 `pipeline/details-exceptions.json`에 있습니다.
- **가운뎃점 통일:** PDF 글꼴에 따라 섞여 나오는 가운뎃점 이형(ㆍ, ･, ⋅ 등)은 `·`(U+00B7)로 통일했습니다.
- **공식 산출물이 아님:** 교육부·국가교육위원회·국립특수교육원의 공식 산출물이 아닙니다. 개별 학생을 진단하거나 개별화교육계획을 대신하지 않습니다.
